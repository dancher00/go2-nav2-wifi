# Point-LIO → Nav2: проверка планирования без движения

Статус: online-планирование по текущим облакам проверено на включённом роботе.
Это ещё не автономная навигация и не локализация в сохранённой PCD-карте.

```bash
GO2_RECORD=1 ./mapping.sh --3d --plan
```

Point-LIO остаётся на Jetson. На ноутбуке существующий TF bridge публикует
`lidar3d_map → base_link` и отдельно `lidar3d_map → lidar3d_sensor` с исходным
временем одометрии. Nav2 ObstacleLayer получает PointCloud2
`/lidar3d/registered`; `sensor_frame=lidar3d_sensor` задаёт фактический центр
лучей. Облако уже в мировой системе, поэтому её начало нельзя использовать
как начало каждого луча. Новых переводчиков часов, фильтров команд или
readiness-узлов нет.

Nav2 использует прежний SmacPlanner2D, rolling costmap 30×30 м с разрешением
0.1 м, obstacle/inflation layers. Неизвестные ячейки непроходимы. RViz
показывает `/global_costmap/costmap` и `/plan`. Контроллер, goal executor,
FollowPath, sport bridge и TCP-передача команд в этом профиле не запускаются.
Общий `./mapping.sh --3d` без `--plan` не запускает Nav2.

Запрос маршрута, координаты цели в текущем `lidar3d_map`:

```bash
python3 ws/scripts/plan-lidar3d.py -0.85 2.65
```

Это только ComputePathToPose. Выберите координаты внутри наблюдаемой свободной
области текущего запуска; пример не гарантированно свободен при другом старте.
Для остановки всей своей сессии — Ctrl+C в терминале mapping. Карта сохраняется
и переносится с Jetson штатным механизмом; отдельные процессы руками убивать
не требуется.

## Проверка 9 сентября 2026

В live-сессии planner активен, costmap 90 000 ячеек: 1596 занятых,
3068 свободных, 85 081 неизвестная. Построен путь 3.66 м / 34 позы.
Все проверенные позиции пути находились в свободных ячейках; проверка
дискретных поз не равна доказательству безопасности непрерывного движения.
TF сенсора разрешался на времени облака. Наблюдалось 15.38 Гц одометрии
и ноль сообщений `/cmd_vel` за диагностический интервал. 113 тестов прошли.
[Измерения](measurements/nav2-pointlio-plan-2026-09-09.json),
[RViz с маршрутом](measurements/nav2-pointlio-plan-rviz-2026-09-09.png).

## Что остаётся перед движением

- Проверить/подготовить скорость корпуса для controller_server: текущая
  `/lidar3d/odom` пригодность twist для контроллера не подтверждает.
- Подключить контроллер к существующему командному тракту после отдельной
  проверки; в этом профиле его нет.
- Проверить footprint при ходьбе: пока унаследован 2D robot_radius=0.22 м.
- Высотный диапазон препятствий 0.15…1.6 м задан в начальной плоскости карты.
  Это просмотр планов на ровном полу; проходимость уклонов, ступеней,
  перепадов и нависающих препятствий не подтверждена.
- Нет глобальной occupancy-карты и повторной локализации после перезапуска.
  Point-LIO остаётся локальной одометрией без loop closure.

Первое автономное движение требует отдельного разрешения пользователя.

Семантика стандартного action:
[Nav2 Humble ComputePathToPose](https://api.nav2.org/actions/humble/computepathtopose.html).
Обработка sensor origin и PointCloud2:
[Nav2 Humble ObstacleLayer](https://api.nav2.org/nav2-humble/html/obstacle__layer_8cpp_source.html).
