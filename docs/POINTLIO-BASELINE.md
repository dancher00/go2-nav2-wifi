# Проверенный Point-LIO baseline — 9 сентября 2026

Git-метка: `pointlio-baseline-2026-09-09`, ветка `experiment/lidar-3d-slam`.
Основная ветка main сохраняет 2D-базу. Камерная ветка не входит в снимок.

```bash
GO2_RECORD=1 ./mapping.sh --3d
```

Считаем на Jetson; RViz получает результат через наш Wi-Fi relay. Сырой L1
и гироскоп LiDAR, без ног, ускорений, камеры и loop closure. Остановка Ctrl+C:
сохранение карты/траектории, выгрузка на ноутбук с проверкой SHA256,
удаление успешно выгруженного результата с Jetson.

На уже установленном окружении перестройка не нужна. Для новой установки
используются `./setup-lidar3d.sh` и
`GO2_ROBOT_IP=<адрес-робота> ./setup-lidar3d-jetson.sh`.
Адрес проверяется перед подключением; SSH запрашивает пароль интерактивно.

Проверенный live-проход: 222.85 с, 3427 поз, невязка возврата 3.0 см по LiDAR
IMU / 3.18 см по корпусу с текущими extrinsics. Это один тест, не гарантия
точности карты. Утолщения стен остаются. [Полные измерения](measurements/pointlio-live-return-2026-09-09.json).

[Манифест](POINTLIO-BASELINE-2026-09-09.json) содержит upstream commit,
SHA256 исходников/конфигурации и точные image ID. На обеих машинах локальный
Docker-тег `go2-lidar3d:baseline-20260909` указывает на проверенный образ
соответствующей архитектуры. Образы не опубликованы в registry;
системные пакетные репозитории не полностью зафиксированы, поэтому повторная
сборка не обещает побитовой идентичности. Git-снимок сохраняет существующий
опциональный Leg-KILO, нужный общим установочным скриптам, но baseline его
не запускает. Незавершённая поправка его экспорта не включена в снимок.

Следующие проверки, после согласования момента движения:

1. Повтор того же круга с отмеченными стартом и направлением корпуса.
2. Тот же маршрут в обратном направлении.
3. Более длинный маршрут с возвратом.

Для каждого: покой 10 с в начале/конце, запись всей сессии, сравнение медиан
позиции корпуса, высоты и совмещения стен. Нагрузку Jetson, bandwidth и
задержки транспорта оцениваем отдельно; restamped headers не считаем
доказательством истинной end-to-end latency. До этих тестов настройки не меняем.
