# Калибровка штатной камеры Go2

Статус: калибровка ещё не получена, рабочие значения не изменены.

## Мишень

`go2-checkerboard-a4.pdf`: A4, альбомная ориентация, 9×6 квадратов по 30 мм
(8×5 внутренних углов). Печатать 100%, без «вписать в страницу». Проверить
линейкой сторону квадрата и закрепить бумагу на плоском жёстком основании.
Экран тоже можно использовать для intrinsics; для метрических операций
нужно отдельно измерить физический размер отображаемого квадрата.

Снимать 25 различных положений: центр, края и углы кадра, несколько расстояний
и наклонов. Весь рисунок должен быть виден, без бликов; между положениями
задерживаться на секунду. Сам робот остаётся неподвижен, перемещается мишень.

Сборщик `ws/scripts/camera_fusion/capture_intrinsics.py` запускается на Jetson,
читает существующий camera IPC, уточняет углы в исходном разрешении и
сохраняет JPEG + NPZ. Близкие повторные положения не засчитываются.
Он только собирает данные; флаг калибровки не устанавливает.

```bash
# В работающем контейнере окраски на Jetson, с новым каталогом вывода:
docker exec go2-camera-fusion python3 /work/camera_fusion/capture_intrinsics.py \
  --output /data/intrinsics-01
```

После сбора требуются оценка intrinsics/distortion и проверка на отдельных
кадрах. Затем — extrinsics камера/лидар на разных расстояниях. Задержка
изображения оценивается отдельной динамической записью: неподвижный ракурс
её не определяет.

## Проведённая попытка без мишени

Запись Jetson:
`~/go2-pointlio-camera-fusion/data/20260910T184155-9828/static-raw-20260910T184714`.
30 пар raw XYZ + intensity и JPEG. Сдвиг изображения p50/p90: 0.119/0.486 px
при размере 640×360. В одном скане 4139 точек, 160 значений интенсивности.

`fit_extrinsic.py` — экспериментальная NumPy/SciPy реализация локального
подбора по нормированной информационной дистанции (NID), с фиксированными
предварительными intrinsics. Метод основан на Koide et al., ICRA 2023:
https://arxiv.org/abs/2302.05094 . Это не полный авторский пакет
https://github.com/koide3/direct_visual_lidar_calibration .

Подбор использует отражательную способность и изображение; контрольные
пространственные плитки исключены из оптимизации. Проверены три начальные
точки. Лучший по обучению вариант снизил train NID с 0.96675 до 0.96522,
но ухудшил контрольный NID с 0.96415 до 0.96563. Вариант отклонён. Числа
не являются ошибкой проекции в пикселях. Поправка не применялась.

Для повторения — системный Python Jetson (SciPy 1.3.3 / системный NumPy),
не DA3-venv: его NumPy несовместим с системным SciPy.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 fit_extrinsic.py <session>
```

Проверено: извлечение intensity на реальных данных, 9 геометрических
регрессий, обнаружение 40 углов тестовой мишени и отбраковка пустого кадра
сборщиком intrinsics на Jetson. SLAM не перезапускался для калибровки.

## Оценка параметров объектива по лабораторной доске

Сессия Jetson: `20260910T184155-9828/intrinsics-lab-board-01`.
Собрано 25 кадров доски с 8×5 внутренними углами и клеткой 30 мм.
Первый расчёт по углам сборщика отклонён: смазанные кадры давали
неустойчивую оценку. `fit_intrinsics.py` повторно распознаёт доску на
полном разрешении через `findChessboardCornersSB`. Отбор не использует
ошибку подгонки; каждый пятый исходный кадр оставлен для проверки.
Поза проверочной доски оценивается по половине углов, ошибка — по остальным.

```bash
docker exec go2-camera-fusion python3 /work/camera_fusion/fit_intrinsics.py \
  /data/intrinsics-lab-board-01 --reference /ipc/calibration.json
```

Диагностический расчёт: 20 распознанных кадров (16 обучение, 4 проверка),
RMS обучения 0.567 px; медиана контрольной ошибки 0.396 px против
0.635 px у исходных параметров. Оценка fx/fy около 1093/1086 px,
стандартная неопределённость около 46/45 px. Модель plumb_bob, k3=0.
Это оценка параметров объектива в текущем режиме 1920×1080,
не подтверждение взаимного положения камеры и лидара или задержки видео.
Скрипт сохраняет отчёт и прошедший проверки профиль отдельно;
не меняет активный профиль и не перезапускает SLAM.
