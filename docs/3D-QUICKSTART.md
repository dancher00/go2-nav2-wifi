# 3D Point-LIO: быстрый запуск

Этот сценарий строит 3D-карту по штатному Unitree L1 и его гироскопу. Point-LIO
работает на Jetson робота, поэтому сырые облака не передаются через Wi-Fi.
Ноутбук запускает RViz, а после остановки получает PCD-карту и траекторию с
проверкой SHA256. Команд движения обычный 3D-режим не отправляет.

## Требования

- Unitree Go2 Edu со штатным `utlidar` и доступом к Jetson по SSH.
- Docker с Compose на ноутбуке и Docker на Jetson.
- Ноутбук и робот в одной Wi-Fi-сети.
- Ubuntu с графической сессией на ноутбуке для RViz.

Клонируйте репозиторий и задайте актуальные адреса:

```bash
git clone https://github.com/dancher00/go2-nav2-wifi.git
cd go2-nav2-wifi
export GO2_HOST_IP=192.168.1.90
export GO2_ROBOT_IP=192.168.1.58
```

## Однократная установка

Сначала подготовьте локальный 3D-контейнер для RViz, затем отдельный контейнер
на Jetson. Оба установщика при необходимости сами собирают базовый
`go2-humble:local` для архитектуры своей машины.

```bash
./setup-lidar3d.sh --laptop
./setup-lidar3d.sh --jetson
```

SSH может запросить пароль пользователя `unitree`. Другой пользователь задаётся
через `GO2_ROBOT_USER`.

## Построение карты

Поставьте робота на ровную поверхность. После запуска держите его неподвижно,
пока в RViz не появится первая карта: Point-LIO накапливает начальные 20 000
точек, обычно это занимает несколько секунд.

```bash
GO2_RECORD=1 ./mapping.sh --3d
```

Ведите робота штатным пультом. Закройте RViz или нажмите Ctrl+C для остановки.
Сессия завершит Point-LIO, проверит результат и перенесёт его в новый каталог:

```text
ws/maps/lidar3d/run-*/
├── PCD/scans.pcd
├── trajectory.tum
├── pointlio.yaml
├── input.json
└── result.json
```

Успешный запуск обязан содержать `result.json`, ненулевые поля `points` и
`trajectory_poses`, а также файлы `PCD/scans.pcd` и `trajectory.tum`. Если
передача оборвалась, результат остаётся на Jetson и может быть получен повторно;
исходная копия удаляется только после совпадения контрольных сумм.

Запись входных данных через `GO2_RECORD=1` нужна для воспроизводимого offline
replay. Для обычной карты её можно отключить:

```bash
./mapping.sh --3d
```

Headless-запуск: `GO2_RVIZ=0 ./mapping.sh --3d`. Вычисления на ноутбуке для
диагностики Wi-Fi: `./mapping.sh --3d --laptop`.

## Что проверено

Последний сохранённый live-запуск после исправления инициализации содержит
2 023 позы и 1 268 914 точек за 131,42 с. На начальной неподвижной части
максимальное оценённое смещение составило 2,92 см. Это проверка устойчивого
старта и согласованности локализации, а не измерение абсолютной точности карты.
Числа и методика: [POINTLIO-LIVE-VALIDATION.md](POINTLIO-LIVE-VALIDATION.md).

Point-LIO в этом профиле не выполняет loop closure. Повторная локализация в
сохранённой карте, длинные маршруты, лестницы и уклоны пока не входят в
проверенный сценарий. Полная история экспериментов и ограничения описаны в
[LIDAR-3D-SLAM.md](LIDAR-3D-SLAM.md).
